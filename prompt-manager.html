Hilfe & Tipps

Wichtige Funktionen

  • Kategorien verwalten: Kategorien anlegen, umbenennen und Prompts über die Detailansicht verschieben
  • Neue Prompts einfügen: Nutze das "+" Symbol für neue Prompts
  • Chat einfügen: Füge einen Chatverlauf ein; Markdown wird live geprüft
  • Import: Bestehende Daten bleiben erhalten, Doppelungen werden übersprungen
  • Backup: Exportiere JSON oder verbinde eine Backup-Datei, die automatisch fortgeschrieben wird

Datensicherheit

Alle Daten werden lokal in deinem Browser gespeichert. Browser-Einstellungen, die Website-Daten beim Schließen löschen, entfernen auch diesen Speicher.

Deshalb: Backup-Datei verbinden (Chrome, Edge, Chromium) oder regelmäßig Export nutzen. Eine verbundene Datei bleibt außerhalb des Browsers erhalten und wird bei jeder Änderung aktualisiert.

Firefox und Safari können Dateien nicht direkt fortschreiben. Dort lädt der Backup-Button stattdessen ein JSON-Backup herunter; nach dem Neustart über Import wiederherstellen. Dauerhaft automatisch speichert der lokale Server: einmalig npm run autostart:install im Projektordner ausführen. Danach genügt ein Klick auf das Lesezeichen http://127.0.0.1:8765/; die App schreibt jede Änderung in prompt-manager-data.json.

Wichtig: Datei und Server sind getrennte Speicher. Nutze dauerhaft denselben Einstieg – am einfachsten das Lesezeichen auf http://127.0.0.1:8765/. Daten aus der Datei lassen sich jederzeit über Import in den Server übernehmen.

Offline und Sicherheit

Die Anwendung lädt nichts aus dem Internet. Externe Bilder in Markdown werden nicht geladen, sondern als Link angezeigt. Links werden nur nach einem Klick geöffnet.
